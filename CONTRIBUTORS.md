# Contributors

See the [GitHub contributors list](https://github.com/OpenGameBuilder/opengamebuilder/graphs/contributors)
for code and documentation contributors, and the repository's
[issues](https://github.com/OpenGameBuilder/opengamebuilder/issues) and
[discussions](https://github.com/OpenGameBuilder/opengamebuilder/discussions)
for reporting, testing, research, and community contributions. Commit counts do
not capture every contribution.

To take part, start with the [contribution guide](CONTRIBUTING.md).
