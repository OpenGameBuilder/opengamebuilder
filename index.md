# OpenGameBuilder documentation

Build and contribute to the independent MyGameBuilder reimplementation.
The application currently provides an API and web shell; the game runtime and
editor are still to come. Read the [project overview](README.md) for current scope.

- [Set up the supported Windows environment](docs/setup/development.md).
- [Find the contribution and support routes](CONTRIBUTING.md).
- [Understand the project boundaries](docs/README.md#repository-map).
- [Run checks and interpret their evidence](docs/quality/testing.md).
- [Deploy, operate, and recover the application](docs/setup/hosting.md).

Use the search box to find procedures across the guides, or use the navigation
to browse by task. Each guide links to its original Markdown for edits.
