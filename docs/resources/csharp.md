# C# Resources

The C# language is the most popular language for the .NET platform, a free, cross-platform, open source development environment.
This page includes a curated list of links on ASP.NET Core relevant to OpenGameBuilder for contributors from beginners to experts.

OpenGameBuilder is implemented almost entirely in C# and uses many modern language features.
