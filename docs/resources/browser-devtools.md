# DevTools Resources

All modern browsers come with DevTools. A curated set of documentation for Chrome's DevTools is listed here,
but the general principles will apply to most browsers.

Note that when debugging the OpenGameBuilder front-end locally, only Chromium based browsers (like Chrome or Edge)
will attach the Blazor app to the Visual Studio debugger.
